MNIST Digit Recognition
This model recognises handwritten digits (**0 to 9**) using Python and Scikit-learn.
Dataset
[MNIST in CSV](https://www.kaggle.com/datasets/oddrationale/mnist-in-csv) from Kaggle, with 60,000 training and 10,000 test images.
Steps
Normalised the pixel values (0 to 1)
Trained Logistic Regression, Random Forest and a Neural Network
Results
| Model | Accuracy |
|-------|---------:|
| Logistic Regression | 92.58% |
| Random Forest | 97.07% |
| **Neural Network** | **98.33%** |
Tools
Python, Pandas, Scikit-learn, Matplotlib, Google Colab
